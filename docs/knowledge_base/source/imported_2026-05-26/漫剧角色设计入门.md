# 漫剧角色设计入门提示词指南

## 标题（概括问题）
AI生成漫剧角色时形象不一致、多画面"穿帮"的问题

## 解决什么问题
解决使用AI生成漫剧角色时，同一人物在不同画面、不同角度、不同场景中形象不一致的问题。具体表现为：脸型忽圆忽方、发色变换不定、侧面崩坏像换人、换场景后服装细节丢失等。

## 问题描述
在用AI生成漫剧分镜画面时，很多创作者会遭遇"角色一致性"暴击：

- 明明描述的是同一个人，AI生成的图却像换了演员——第一张是圆脸，第二张变方脸；第一张黑头发，第二张带棕色调。
- 正面看起来还行，侧面就崩了，像另一个人。
- 换了场景之后，主角的衣服颜色、发型细节全变了。

根因在于：AI生图和人类画画不一样。人类画师画同一个角色，脑子里有"这个人长什么样"的完整概念。但AI没有——每次生成，它都是根据你给的提示词，从零开始"猜"一张图。如果每次提示词写得不一样，AI猜出来的结果自然不一样。

## 常见原因
1. 每次生图提示词描述不一致，AI从零"猜测"导致结果不同
2. 角色描述用词过于模糊，如"好看""可爱"在不同模型中指向不同视觉特征
3. 场景提示词覆盖了角色描述，导致换场景后角色外貌变化
4. 标志性特征（眼镜、痣、发型等）在提示词中权重不够，被AI忽略
5. 缺乏多角度参考图，AI对角色侧面、背面等角度理解不足

## 解决步骤
### 第一步：建立角色设定卡——固化描述模板
给AI一张"标准答案"，把对角色的所有描述固化成一个固定的提示词模板，每次生图都用同一套描述。以下是实测AI理解最稳定的角色设定卡模板：

**角色设定卡（填空版）**
- 【角色名称】：给角色起一个名字，如"小美"
- 【性别/年龄】：女/25岁 或 男/30岁
- 【脸型】：圆脸/瓜子脸/方脸
- 【眼睛】：大眼/细长眼/圆眼，颜色：黑/棕/蓝
- 【发型】：长发/短发/马尾，颜色：黑色/棕色/金色，是否有刘海
- 【体型】：苗条/匀称/丰满
- 【服装】：上装+下装+鞋子，具体描述，如"白色衬衫+黑色牛仔裤+白色运动鞋"
- 【标志性特征】：如"左眼下有一颗泪痣"或"戴着一副圆框眼镜"
- 【风格】：日系动漫/国漫写实/美式卡通

**使用示例（主角"打工人小张"）：**
- 【角色名称】：小张
- 【性别/年龄】：男/28岁
- 【脸型】：方脸，下巴略圆
- 【眼睛】：中等大小，深棕色瞳孔，眼神疲惫（有黑眼圈）
- 【发型】：黑色短发，有点乱，前额有几根碎发
- 【体型】：偏瘦，肩膀略窄
- 【服装】：深蓝色格子衬衫+卡其色长裤+黑色运动鞋
- 【标志性特征】：戴一副黑色圆框眼镜，左眉尾有一道小疤痕
- 【风格】：国漫写实风格，略带疲惫的打工人质感

每次生图时，把完整的角色设定卡原封不动地放进提示词里，不要删减任何一个词。一致性是靠"重复"保住的。

### 第二步：生成多角度角色图构建素材库
有了设定卡后，逐角度生成角色的正面、侧面、半身、全身图，作为后续分镜的素材库。以文心一格或通义万相为例：

- 生成正面标准照：提示词中加入"正面半身照，白色背景，光线均匀，角色直视镜头"
- 生成侧面照：提示词中加入"侧面视角，脸转向左侧"，其他设定不变
- 生成全身照：提示词中加入"全身站立，双脚着地，正面视角"
- 生成不同表情：提示词中加入"表情：微笑/惊讶/愤怒/悲伤"

每次生成都复制完整的角色设定卡，保持描述一致性。

### 第三步：用参考图+图生图锁死一致性
如果纯靠文字设定还不够稳，使用图生图功能进行双重锁定：

- 从多角度图中挑一张最像角色的正面图，作为"母图"
- 在生成新图时，上传这张母图作为参考
- 设置参考强度（通义万相中叫"相似度"），建议0.6-0.8，太高会完全复制姿势，太低会偏离
- 输入新的场景描述，如"侧面视角"或"坐在办公室里"

参考图+文字描述是当前最稳的一致性方案。如果免费工具不支持参考图，靠足够详细的文字描述也能做到80%一致。

## 总结
AI生成漫剧角色一致性的核心方法：

1. 建立角色设定卡，固化所有外貌描述，每次生图都用同一套模板
2. 先生成一套多角度角色图（正、侧、背、斜45度），作为素材库
3. 用参考图+图生图双重锁定一致性，文字和图像双向约束
4. 角色描述用词要具体明确，避免模糊词汇如"好看""深色"
5. 标志性特征在提示词中可重复强调，确保不被AI忽略
6. 服装描述放在提示词最前面，避免被场景描述覆盖

注意：专业动画中同一角色在不同镜头也会有细微差异。观众能接受的"像"大约是90%相似。只要脸型、发型、主要特征（眼镜、痣）不变，衣服颜色一致，观众就不会出戏。角色设定卡能做到70分就够用了，剩下的靠剧情和情绪补上。

## 进一步提升
### 怎么提升
在角色设定卡基础上，针对不同生图场景加入场景适配参数，提升多场景下的一致性：

**场景适配公式：**
角色设定卡（完整复制） + 视角描述 + 场景氛围 + 动作/表情 + 画质参数

关键技巧：
- 服装描述始终放在提示词最前面，优先级高于场景
- 标志性特征在提示词中出现两次以上，增加权重
- 每次生成后对比母图，发现偏差及时调整提示词中对应的描述项
- 建立专属的角色素材文件夹，按"正面/侧面/背面/表情/场景"分类保存

## 输出格式
AI漫剧角色生成提示词应遵循以下结构：

1. **角色设定卡（完整复制）**：包含角色名称、性别年龄、脸型、眼睛、发型、体型、服装、标志性特征、风格
2. **视角描述**：正面/侧面/背面/半身/全身/特写
3. **场景氛围**：环境描述和光线氛围
4. **动作/表情**：角色当前的动作和表情状态
5. **画质参数**：风格、精度、比例等（如"国漫写实风格""日系动漫风格""高精度""16:9"）

每次生图都必须完整复制角色设定卡的全部九项内容，不可删减。场景和动作描述不覆盖角色固有特征。

- 背面照：角色背对镜头，展示发型和服装背面
后续生图时，根据需要的角度选择最接近的参考图上传，结合角色设定卡文字描述，双重约束。

**问题：**如何用免费工具实现角色一致性？

- 角色C（元气少女）：女/18岁，圆润的鹅蛋脸，大圆眼棕色瞳孔活泼灵动，金色双马尾用星星发夹固定，身材娇小，粉色连帽卫衣+白色百褶短裙+白色过膝袜+粉色运动鞋，国漫热血风格
三人站在一起时，身高差（B最高、A中等、C最矮）和配色差（红、蓝、粉）形成鲜明区分。群像的关键是：风格统一+配色差异化+体型差异化。

**问题：**如何生成角色的"成长过程"系列图（从幼年到成年）？

**输出示例10（角色成长系列）：**
基础设定：女，圆脸，黑色大眼，黑色长发，日系动漫风格。
- 5岁幼儿期：身高矮小，黑色短发童花头，圆脸婴儿肥明显，穿粉色连衣裙+白色小皮鞋，抱着毛绒玩具熊
- 12岁少年期：身高抽条，黑色长发及肩扎成单马尾，圆脸逐渐退去婴儿肥但仍有稚气，穿白色校服衬衫+深蓝色背带裙，背着书包
- 18岁青春期：身高接近成人，黑色长发及腰，脸型从圆脸过渡到鹅蛋脸，穿白色衬衫+格子短裙+黑色中筒袜，表情自信

成长系列的核心是：面部特征逐步过渡而非突变，同时保留能够串联各个年龄段的共有特征（本例中贯穿的特征是黑色头发和逐渐成型的脸型）。

**问题：**如何为一个非人种族角色（如精灵、兽人）建立稳定的设定卡？

**输出示例11（非人种族设定）：**
角色设定卡：精灵族女性/外表年龄25岁（实际年龄300岁），精致的鹅蛋脸皮肤白皙近乎透明，杏仁形眼睛紫色瞳孔眼尾微挑像猫眼，银白色长发及腰有自然波浪卷，尖耳朵从发丝间露出长约5cm，身材高挑纤细，穿月白色丝质长袍用银色藤蔓纹腰带束腰+赤足，额间有一枚浅蓝色菱形晶石镶嵌，周身有淡淡微光粒子环绕，西方奇幻写实风格。
- 森林场景：全身侧面，赤足走在月光下的森林中，长发和长袍被微风轻拂，手指轻触树干，指尖与树木接触处泛起微光
- 战斗场景：全身正面45度角，拉开银色长弓对准远方，银发因拉弓动作向后飞扬，表情冷静专注，微光粒子在拉弓的手臂周围加速旋转
非人种族的设定卡要着重描述"非人特征"——耳朵形状、皮肤质感、发光效果等——这些是区分于普通人类的关键，必须在每张图中保持稳定。

**问题：**如何在同一个画面中保持两名角色一致的互动关系？

**输出示例12（双人互动一致性）：**
使用两张独立设定卡 + 一张互动关系卡：
- 角色A设定：男/28岁，方脸略圆，深棕色眼睛有黑眼圈，黑色圆框眼镜，深蓝色格子衬衫，卡其色长裤，国漫写实风格
- 角色B设定：女/25岁，瓜子脸，黑色长直发齐刘海，左眼下泪痣，白色衬衫，深蓝色百褶裙，日系动漫风格
- 互动关系卡（双人共用）：两人面对面站在天台边缘，距离约50cm，A身体微微前倾一只手伸向B的方向掌心朝上，B双手背在身后身体略后仰嘴角带着调皮的笑意，夕阳逆光打在两人身上形成暖橙色剪影，中景构图
关键技巧：双人场景中，先各自复制完整的独立设定卡，再用互动关系卡描述肢体距离、视线方向和互动节奏，确保两人的特征互不覆盖、关系明确。

## 相关问题
1. **脸型不统一问题：**每次生成脸型都不一样，如何解决？
   - 解决方案：设定卡中使用具体脸型词（圆脸、方脸、瓜子脸），杜绝模糊词如"好看""漂亮"。

2. **发色漂移问题：**发色在不同画面中总是变化？
   - 解决方案：固定写"黑色短发"，不要用"深色头发"这类模糊词。颜色词前置并重复。

3. **服装丢失问题：**换场景后衣服变了？
   - 解决方案：每次生图都把服装描述放在提示词最前面，确保优先级高于场景。

4. **标志特征消失问题：**眼镜、痣等特征时有时无？
   - 解决方案：在提示词中用强调句式写两遍，如"戴黑色圆框眼镜，眼镜不能少"。

5. **侧面崩坏问题：**侧面完全不像？
   - 解决方案：先生成一组多角度图（正、侧、背、斜45度），全部保存，每次挑一张最像的做参考图。

6. **风格跳跃问题：**同一角色在不同画面中风格不统一？
   - 解决方案：设定卡中明确固定风格关键词（如"国漫写实"），每次都用同一个风格词，不要混用。

7. **年龄感偏移问题：**同一角色在不同图中显得年龄不同？
   - 解决方案：年龄描述结合具体特征（如"28岁，眼角有细微笑纹，略成熟"），而不是只写数字。

8. **体型不一致问题：**角色的胖瘦高矮在不同画面中变化？
   - 解决方案：体型描述加入身材比例细节（如"偏瘦，肩宽与胯宽比例约1:1"），增强约束力。
