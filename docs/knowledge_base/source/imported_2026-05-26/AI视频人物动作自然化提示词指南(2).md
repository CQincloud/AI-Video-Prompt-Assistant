# AI视频人物动作自然化提示词指南

## 标题（概括问题）
AI视频人物动作僵硬不自然的问题

## 解决什么问题
解决AI生成视频中人物动作僵硬、不连贯、不符合角色气质和场景氛围的问题

## 问题描述
AI视频与AI图片最大的区别在于视频有时间变化，需要人物从一个状态过渡到另一个状态。如果动作过程描述不清，视频容易出现不连贯、动作僵硬、与角色身份不匹配等问题。常见问题包括：
- 动作幅度过大或过小
- 动作速度不符合角色气质
- 动作方式偏现代感
- 身体部位动作孤立，缺乏联动
- 缺乏情绪和状态表达

## 常见原因
1. 提示词过于简单，只描述动作结果，不描述过程
2. 未考虑角色身份和场景氛围对动作的影响
3. 忽略身体各部位的联动关系
4. 缺乏情绪和状态表达
5. 多人画面未分角色描述互动

## 解决步骤
### 第一步：写清楚人物的步态
不要只写"人物向前走"，要具体描述"怎么走"。例如：
- 步履从容、端庄稳重地前行
- 小心翼翼、收敛克制地迈步
- 大步流星、意气风发地阔步
- 蹒跚迟缓、疲惫不堪地挪动
- 符合角色身份和场景氛围的步态

### 第二步：加入身体联动
真实人物动作不会只有一个部位在动。例如：
- 抬头远望时，视线随之移动，肩胛轻微后收，手臂连带手中物件产生细微晃动
- 转身回眸时，腰部带动上身旋转，肩膀随之下沉，头部顺势偏转
- 坐下时，膝盖弯曲、身体重心后移、双手自然扶住扶手或撑在身后
- 挥手告别时，手腕带动前臂，肘部微屈，肩膀配合轻摆
- 动作要轻，重点放在头部、肩膀、手臂和上身的微小变化上

### 第三步：加入情绪和状态
让人物带着情绪做动作，而不是单纯执行机械动作。例如：
- 压抑着怒火、隐忍不发地低头翻阅文件
- 震惊过后强行平复心情、努力保持镇定的状态
- 欣喜若狂、手舞足蹈地奔向远方
- 忧心忡忡、眉头紧锁地来回踱步
- 眼神闪烁、呼吸急促、手上力度时紧时松
- 动作前面加原因，动作里面加情绪，动作后面加状态

### 第四步：把动作拆成动作链
将单一动作拆解为完整的过程，让AI理解动作从开始到结束的完整流程：
1. 起始状态
2. 蓄力动作
3. 发力部位
4. 动作方向
5. 运动轨迹
6. 结束姿势
7. 镜头配合

### 第五步：多人画面分角色写
不要只写"两人对视"，要分角色描述互动过程：
- 谁先动，谁回应
- 每个人的具体动作
- 互动顺序和节奏
- 最终停在哪一种关系状态

## 总结
AI视频人物动作自然化的核心是让动作描述更清楚、更符合角色气质。重点包括：
1. 写清楚人物怎么动，而不是只写动作名称
2. 加入辅助动态让视频不单调
3. 动作要有身体各部位的联动
4. 加入情绪和状态表达
5. 把动作写成简单动作链
6. 多人画面分角色描述互动

## 进一步提升
### 怎么提升
使用AI视频人物动作通用模板，确保提示词包含所有关键要素：

**模板公式：**
人物身份 + 场景氛围 + 情绪状态 + 主动作 + 辅助动态 + 身体联动 + 结束状态 + 简单镜头

## 输出格式
AI视频人物动作提示词应遵循以下结构：
1. 人物身份：明确角色是谁
2. 场景氛围：描述环境和氛围
3. 情绪状态：表达人物当前情绪
4. 主动作：主要动作描述
5. 辅助动态：小动作增加自然感
6. 身体联动：各部位配合关系
7. 结束状态：动作完成后的状态
8. 简单镜头：镜头运动方式

## 相关问题
1. **动作幅度控制问题：**如何平衡动作幅度与角色气质？
   - 解决方案：根据角色身份和场景氛围调整动作幅度，如宫廷女子动作应端庄克制，侠客动作可有力洒脱。

2. **动作速度问题：**如何控制动作节奏？
   - 解决方案：在提示词中加入速度描述词，如"缓缓地"、"快速地"、"有节奏地"等。

3. **多人互动问题：**如何处理多人场景的动作协调？
   - 解决方案：分角色描述，明确谁主动谁回应，建立互动顺序和节奏。

4. **镜头配合问题：**如何让镜头运动增强动作表现？
   - 解决方案：根据动作方向设计镜头运动，如跟随、推进、后退等，增强动作的视觉冲击力。

5. **情绪表达问题：**如何通过动作传达复杂情绪？
   - 解决方案：在动作描述中加入情绪状态词，并描述情绪对动作细节的影响，如"压抑地"、"决绝地"、"犹豫地"等。

6. **物体交互问题：**如何让人物与物体的互动更自然？
   - 解决方案：描述物体在动作中的位置、受力变化和运动轨迹，如"手中的茶杯随着放下动作产生轻微涟漪"。

7. **场景切换问题：**如何让人物在不同场景间的过渡更流畅？
   - 解决方案：利用动作衔接场景变化，如在行走中自然穿越门廊、转身时背景顺势过渡。

8. **重复动作问题：**如何避免循环动作的机械感？
   - 解决方案：在重复动作中加入微小变化，如每次挥手的幅度、速度略有不同，或穿插辅助小动作打破循环。
