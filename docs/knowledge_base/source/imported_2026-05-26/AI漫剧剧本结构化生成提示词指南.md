# AI漫剧剧本结构化生成提示词指南

## 标题（概括问题）
AI漫剧剧本生成输出格式不规范，无法直接对接分镜工具

## 解决什么问题
解决AI生成漫剧剧本时输出格式不统一、结构混乱、无法被下游分镜和视频生成管线直接解析和使用的核心问题，实现从创意到可执行结构化脚本的一键生成。

## 问题描述
传统影视剧本以对白和场景描述为主，漫剧制作的第一步不是画画而是写剧本。但传统剧本格式无法直接喂给AI分镜工具——需要一种"机器可读"的结构化脚本格式。常见问题包括：
- 输出为自然语言描述，无法被程序自动解析
- 缺少明确的字段定义（场景ID、运镜方式、时长等）
- 角色特征在不同场景中不一致
- 场景时长分配不均，影响视频节奏
- 镜头语言单调，缺乏变化
- 相邻场景之间缺乏逻辑过渡

## 常见原因
1. 提示词过于笼统，只要求"写一个好故事"，未指定结构化输出格式
2. 未给AI提供明确的字段约束和JSON Schema定义
3. 缺少角色设定表作为输入，导致AI凭空想象角色特征
4. 未对场景参数（时长、景别数量、场景数）设定硬性约束
5. 生成后缺乏自动化格式校验机制，质量问题难以及时发现

## 解决步骤
### 第一步：故事大纲生成
从一句话创意出发，让AI扩展为完整的故事大纲。给AI明确的约束（集数、场景数、风格）比笼统的描述效果好得多。

提示词模板：
```
你是一个专业的漫剧编剧。请根据以下创意生成一份漫剧故事大纲。
创意：{一句话描述}
目标受众：{受众群体}
风格基调：{搞笑/悬疑/治愈/热血}
集数：{N}集，每集{M}个场景
请输出：
1. 核心冲突
2. 主要角色（姓名、性格、外貌特征）
3. 每集概要（1-2句话）
4. 故事弧线（起承转合）
```

### 第二步：角色设定表生成
角色设定表是保证批量生成时角色一致性的基础。让AI输出包含外貌描述、标志性特征和AI绘图提示词的结构化角色数据。

提示词模板：
```
基于以下故事大纲，为每个主要角色生成详细设定表。
故事大纲：{上一步输出}
每个角色需要包含：
- 姓名、年龄
- 性格关键词（3-5个）
- 外貌描述（用于AI绘图，需包含：发型、发色、瞳色、服装、体型）
- 标志性特征（如：总是戴着红色围巾）
- Stable Diffusion提示词（英文，用于生成角色参考图）
输出格式：JSON
```

输出示例：
```json
{
  "name": "林小雨",
  "age": 22,
  "personality": ["活泼", "好奇心强", "话多", "善良"],
  "appearance": "黑色短发齐肩，棕色瞳孔，身穿白色连衣裙搭配牛仔外套",
  "signature": "左手腕上总戴着一串木珠手链",
  "sd_prompt": "1girl, short black hair, shoulder length, brown eyes, white dress, denim jacket, wooden bead bracelet on left wrist, anime style, detailed face"
}
```

### 第三步：分场景脚本生成
将故事大纲展开为可执行的结构化脚本，这是最关键的一步。每个场景必须包含完整的字段集合。

提示词模板：
```
你是一个漫剧分镜编剧。请将以下故事大纲的第{N}集展开为详细的分场景脚本。
故事大纲：{大纲}
角色设定：{角色表}
本集概要：{第N集概要}
要求：
1. 每个场景包含字段：scene_id, location, characters, action, dialogue, camera, mood, duration
2. camera使用标准镜头语言：特写/近景/中景/全景/远景 + 运镜方式
3. duration单位为秒，每个场景3-6秒
4. 每集控制在8-15个场景
5. 输出格式为JSON数组
```

### 第四步：脚本质量检查与优化
AI生成的初稿通常需要一轮优化才能投入生产。

常见问题及修复方案：
- 场景跳跃过快：在提示词中要求"相邻场景需要有逻辑过渡"
- 角色行为不一致：在提示词中附上角色性格约束
- 镜头语言单调：要求"至少包含3种不同景别"
- 时长分配不均：设定硬性约束"每场景3-6秒"

自动化校验脚本：
```python
required_fields = ["scene_id", "location", "characters", "action", "camera", "mood", "duration"]
for scene in script["scenes"]:
    missing = [f for f in required_fields if f not in scene]
    if missing:
        print(f"Scene {scene.get('scene_id', '?')}: 缺少字段 {missing}")
    if not 3 <= scene.get("duration", 0) <= 6:
        print(f"Scene {scene['scene_id']}: 时长 {scene['duration']}s 超出范围")
```

## 总结
AI漫剧剧本结构化生成的核心是让AI输出"机器可读"的JSON格式脚本，而非自然语言故事。重点包括：
1. 从故事大纲到角色设定到分场景脚本的渐进式生成流程
2. 每个环节都使用明确的提示词模板和输出格式约束
3. 角色设定表确保跨场景的角色一致性
4. 结构化字段可直接映射到分镜生成管线的输入参数
5. 输出后进行格式校验，确保字段完整性和数值范围合规
6. 约束越具体，AI输出越稳定和可预测

## 进一步提升
### 怎么提升

## 输出格式
AI漫剧剧本结构化提示词输出应遵循以下JSON结构：
1. episode：集数编号
2. title：本集标题
3. scenes：场景数组，每个场景包含：
   - scene_id：场景序号
   - location：场景地点与氛围描述（可直接映射为AI分镜的背景提示词）
   - characters：出场的角色名称列表（用于选择对应的角色LoRA模型）
   - action：角色动作描述（映射为运动描述输入）
   - dialogue：对白内容
   - camera：镜头语言——景别（特写/近景/中景/全景/远景）+ 运镜方式（映射为构图控制参数）
   - mood：场景情绪基调
   - duration：场景时长（秒），控制视频片段时间

## 相关问题
1. **JSON格式不稳定问题：**AI输出的JSON格式偶有语法错误怎么办？
   - 解决方案：在提示词末尾加上"严格按照以下JSON Schema输出"并附上Schema定义；生成后用Python的json.loads()做格式校验，失败则自动重试。

2. **角色一致性问题：**批量生成多集时角色特征不一致怎么办？
   - 解决方案：每集生成时在提示词中附上完整的角色设定表作为上下文约束，利用AI的长上下文能力保持一致性。

3. **场景过渡问题：**场景之间跳跃过快，缺乏流畅感怎么办？
   - 解决方案：在分场景提示词中明确要求"相邻场景需要有逻辑过渡"，可在提示词中给出一两个过渡示例。

4. **镜头语言单调问题：**全剧使用同一景别导致视觉疲劳怎么办？
   - 解决方案：在提示词中硬性要求"每集至少包含3种不同景别（特写/近景/中景/全景/远景）"，并提供camera字段的标准用语库。

5. **时长控制问题：**场景时长差异过大导致视频节奏失控怎么办？
   - 解决方案：设定硬性约束"每场景3-6秒"，并在质量检查步骤中通过脚本自动校验。

6. **对白自然度问题：**AI生成的对白生硬不自然怎么办？
   - 解决方案：在角色设定中明确每个角色的说话风格（语气词、习惯用语），在分场景提示词中要求"对白需符合角色性格"。

7. **格式扩展问题：**需要为特殊类型漫剧添加自定义字段怎么办？
   - 解决方案：在基础JSON Schema上扩展自定义字段，如战斗漫剧可添加"sfx"（音效）和"vfx"（特效）字段，在提示词中说明新增字段的用途和取值规范。

8. **批量生成效率问题：**需要一次性生成多集脚本，如何提高效率？
   - 解决方案：先生成全局故事大纲和角色设定表，然后以集为单位并行调用AI生成各集脚本，最后汇总做格式校验。利用脚本自动化管理输入输出，减少手动操作。
