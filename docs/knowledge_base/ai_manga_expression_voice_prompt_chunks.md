# AI漫剧人物表情语气提示词知识块

本文档用于回答人物表情提示词、表情语气、台词语气、面部细节、微表情、眼神、眉毛、嘴角、唇部、声音/台词和情绪表达相关问题。

## 表情语气模板的边界

表情语气模板应聚焦脸部细节和声音表达，不应该默认加入身体动作、走位、手势或动作链。

适合写入表情语气模板的内容：

眼神：直视、闪躲、游离、失焦、压迫、湿润、泛红、眼神空洞。

眉毛：眉心收紧、眉尾下压、眉峰轻挑、双眉微皱、眉毛放松。

眼睑：半垂、睁大、轻颤、眼尾紧绷、上眼睑下压。

嘴角：轻微上扬、下压、僵住、克制地抿住。

唇部：微张、紧抿、发颤、咬唇、干涩、欲言又止。

面部肌肉：下颌收紧、脸颊僵住、鼻翼轻动、喉咙发紧。

情绪层次：表面情绪和隐藏情绪，例如表面平静，底层压抑愤怒。

台词语气：音量、语速、停顿、气息、尾音、咬字力度。

不应默认写入的内容：

走路、转身、伸手、抱臂、后退、扶桌、拿东西、衣摆晃动、身体重心变化、复杂运镜、全身动作链。

如果用户明确要求视频动作或肢体表演，再转到动作自然化模板；如果只问表情语气，就不要混入动作。

## 表情语气提示词结构

可复制表情语气提示词建议包含：

脸部景别：面部特写、近景、眼部特写、嘴唇特写。

基础情绪：平静、愤怒、委屈、震惊、压抑、悲伤、羞怯、讽刺。

眼神细节：视线方向、聚焦状态、眼眶变化。

眉眼变化：眉毛、眼睑、眼尾、眉心。

嘴部变化：嘴角、唇部、咬字状态。

面部肌肉：下颌、脸颊、鼻翼、喉咙等细节。

台词语气：音量、语速、停顿、气息、尾音和潜台词。

负面提示词：不要全身动作、手势、走位、道具、夸张表情、五官畸形、表情过度卡通化。

## 表情语气示例

压抑愤怒：

正向提示词：
面部特写，角色表面强装平静，
眼神直视前方但瞳孔微微收紧，
眉心轻压，眉尾下沉，
嘴唇紧抿，嘴角几乎没有弧度，
下颌线绷紧，鼻翼有很轻的起伏。
说话音量压低，语速慢，
每句话之间有短暂停顿，
尾音被刻意压住，像在控制怒意。

负面提示词：
不要走路、转身、伸手、抱臂、后退。
不要全身动作、手势、手持道具。
不要夸张怒吼、夸张张嘴、漫画式表情。
不要五官变形、表情过度、眼睛不一致。

欲言又止：

正向提示词：
近景面部，角色想开口却停住，
视线先短暂聚焦，随后轻微闪躲，
上眼睑微垂，眼尾带一点迟疑，
嘴唇微张又合上，嘴角轻轻下压，
下颌放松但喉咙像被堵住。
台词语气很轻，气息短，
句子开头犹豫，尾音中断，
像把真正想说的话咽了回去。

负面提示词：
不要身体后退、转身离开、抓衣袖。
不要复杂动作链、不要道具。
不要夸张哭泣、夸张表演、卡通表情。

## 输出规则

当用户要求表情提示词、表情语气模板或台词语气模板时，最终【示例提示词】或【优化后提示词】必须只围绕脸部和声音表达写。动作模板中的“主动作、辅助动态、身体联动、结束状态”不适用于表情语气模板。
