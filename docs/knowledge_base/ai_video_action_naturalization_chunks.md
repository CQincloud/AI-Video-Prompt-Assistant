## chunk_001：文档用途与适用场景

元数据建议：`doc_id=video_action_naturalization_guide`，`content_type=scope`，`category=AI视频生成`，`sub_category=人物动作提示词`，`problem_types=["动作僵硬","动作不自然","动作不连贯"]`，`action_types=["走路","转身","回头","多人互动","镜头配合"]`，`styles=["通用","古风","现代"]`，`priority=10`。

本知识块用于回答 AI 视频人物动作僵硬、不自然、不连贯、缺乏情绪、缺乏身体联动、人物走路像机器人、动作与镜头脱节等问题。适合 AI 视频创作者、短剧创作者、提示词工程师和 AI 视频生成用户。

优先检索场景包括：用户询问人物走路自然化、转身动作、回头动作、抬头低头、伸手触碰、多人物对视或互动、古风人物动作、动作幅度控制、动作速度控制、动作提示词改写、镜头如何配合人物动作。常见问法包括“AI 视频里人物动作僵硬怎么办”“人物转身怎么写才自然”“古风女子走路提示词怎么写”“两个人对视怎么写”“动作太现代怎么改”。

不优先使用场景包括：纯图片生成提示词、人物长相设计、服装设定、场景美术、光影色彩、分镜脚本结构、剧情大纲、剪辑节奏、音效配乐和字幕制作。如果用户问题同时涉及动作与画面、镜头、剧情，应优先用本知识块解决动作自然化，再结合其他知识库补充。

## chunk_002：AI视频人物动作僵硬的核心原因

元数据建议：`content_type=diagnosis`，`problem_types=["动作僵硬","动作不自然","动作跳跃","动作机械"]`，`action_types=["通用"]`，`priority=10`。

AI 视频与 AI 图片的核心区别是视频存在时间变化，人物必须从一个状态自然过渡到另一个状态。如果提示词只写动作结果，不写动作过程，生成视频就容易出现人物僵硬、动作不连贯、身体部位缺乏联动、速度或幅度不符合角色身份、动作过于现代、多人互动没有先后顺序、镜头运动和人物动作脱节等问题。

诊断时优先看五点：第一，是否只写“人物向前走、人物转身、两人对视”这类结果，没有写“怎么走、怎么转、谁先看谁”。第二，是否没有写角色身份和气质，例如宫廷女子应端庄克制，侠客应利落有力，老人应缓慢沉稳，受伤角色应身体不稳。第三，是否忽略身体联动，例如抬头要写视线、脖颈、肩膀、上身，转身要写头部、肩膀、上身和衣摆先后变化。第四，是否缺少情绪状态，同样是低头，失落、羞涩、警觉、压抑的动作完全不同。第五，多人画面是否没有分角色描述谁先动、谁回应、最后保持什么距离和状态。

回答用户时可以指出：你的问题主要是动作只写了结果，没有写清楚过程。优化方向是补充动作链、身体联动、情绪状态、角色身份和结束姿势。

## chunk_003：人物步态写法

元数据建议：`content_type=method`，`problem_types=["走路僵硬","步态不自然","角色气质不足"]`，`action_types=["行走","靠近","后退"]`，`styles=["通用","古风","受伤"]`，`priority=10`。

人物走路不要只写“人物向前走”，要写清楚人物是怎么走的。步态应结合角色身份、年龄状态、情绪状态、场景氛围、动作速度、动作幅度、身体重心和结束状态。

常用步态词：缓慢类可写“缓慢地走、缓缓向前、脚步放轻、平稳移动”；轻快类可写“轻快地走、步伐有节奏、身体轻微起伏、双臂自然摆动”；谨慎类可写“试探性迈步、眼神观察四周、身体保持紧绷、动作克制警觉”；端庄类可写“步伐平稳、身体挺直、动作克制、手部动作轻柔、整体气质沉稳”；受伤类可写“脚步不稳、身体微微前倾、一只手扶住身体、呼吸沉重、停顿时身体轻微晃动”。

错误示例：“古风女子在街上走。”问题是没有步态、情绪、身体联动、镜头和结束状态。优化示例：“古风女子站在夜晚古街中，带着谨慎和警觉的情绪缓慢向前行走。她的脚步放轻，身体保持克制，右手轻轻提起裙摆，左手自然垂落。肩膀随着步伐轻微起伏，发丝和衣袖在夜风中轻轻晃动。她一边前行一边用眼神观察四周，最后在街角灯笼下停住，微微侧身回望来路。镜头采用中近景侧面跟随拍摄。”

## chunk_004：身体联动写法

元数据建议：`content_type=method`，`problem_types=["身体部位孤立","动作僵硬","联动不足"]`，`action_types=["抬头","低头","转身","回头","伸手","坐下"]`，`priority=10`。

身体联动是让人物动作自然的关键。真实人物做动作时，通常不是某一个部位单独运动，而是视线、头部、肩膀、上身、手臂、重心、衣摆和呼吸共同参与。

抬头：不要只写“人物抬头”，可写“人物先短暂停顿，随后缓缓抬起头，视线从地面移动到前方，肩膀随着呼吸轻微放松，上身略微挺直，眼神逐渐变得坚定”。

低头：可写“人物听到声音后微微一怔，眼神先向下偏移，随后缓慢低下头，肩膀轻轻收紧，手指不自觉握紧衣袖，整体状态显得压抑而克制”。

转身：可写“人物听到身后动静后先停住脚步，眼神微微变化，随后头部先向后偏转，肩膀和上身跟随转动，衣摆随着身体转向轻轻摆动，最后侧身站定看向身后”。

回头：可写“人物向前走了几步后放慢脚步，眼神先向身后偏移，随后缓缓回头，肩膀轻微跟随转动，发丝被动作带起轻轻晃动，最后停在半侧身状态”。

伸手和坐下也要写准备动作、手臂轨迹、肩膀状态、重心变化和结束点，例如“手停在半空，像是还没有下定决心”或“身体重心下移，衣摆自然垂落，最后平稳坐下”。

## chunk_005：情绪和状态写法

元数据建议：`content_type=method`，`problem_types=["动作没有情绪","角色感不足","剧情感不足"]`，`action_types=["通用"]`，`emotion_types=["紧张","压抑","犹豫","坚定","惊讶","疲惫"]`，`priority=9`。

动作要服务于人物情绪。没有情绪时，动作容易像执行命令；加入情绪后，动作才会有角色感和剧情感。通用公式是：触发原因 + 情绪状态 + 动作过程 + 身体细节 + 结束状态。

表现紧张：写“人物听到远处脚步声后身体微微一僵，眼神变得警觉。他放慢呼吸，谨慎地向后退半步，肩膀微微收紧，手指轻轻握住衣角，最后停在原地观察四周”。

表现压抑：写“人物听完对方的话后短暂沉默，眼神逐渐低垂，肩膀微微下沉。他缓慢低下头，手指用力握紧袖口，呼吸变得克制，最后站在原地没有说话”。

表现犹豫：写“人物站在门前停顿片刻，眼神在门口和身后之间移动。他缓缓抬起手想要推门，但指尖在半空停住，肩膀略微紧绷，最后仍然没有立刻行动”。

表现坚定：写“人物在短暂沉默后缓缓抬头，眼神逐渐变得坚定。他挺直上身，脚步平稳地向前迈出，肩膀放松但姿态有力，最后站定在对方面前”。

## chunk_006：动作链写法

元数据建议：`content_type=template`，`problem_types=["动作不连贯","动作跳跃","视频突兀"]`，`action_types=["转身","抬头","伸手","坐下","回头"]`，`priority=10`。

AI 视频需要理解动作从开始到结束的过程。完整动作链可以拆成 8 个部分：起始状态、触发原因、蓄力动作、发力部位、动作方向、运动轨迹、结束姿势、镜头配合。

动作链模板：人物处于什么状态，因为某个原因产生动作。动作开始前先出现轻微停顿或准备动作，随后由某个身体部位带动整体动作，按照某个方向和轨迹完成动作。动作结束后人物停留在某种姿势或情绪状态中，镜头以某种方式配合动作。

转身示例：黑衣男子站在昏暗的巷口，听到身后传来轻微声响后，身体先短暂停顿。随后他的眼神向后偏移，头部率先转向声音来源，肩膀和上身跟随转动，衣摆随着身体转向轻轻摆动。他最终停在半侧身姿势，目光警觉地望向身后。镜头采用中近景缓慢推进，突出紧张氛围。

伸手触碰示例：女子站在古老的石门前，神情犹豫。她先停顿片刻，目光落在石门纹路上，随后缓缓抬起右手，手臂从身体一侧慢慢向前伸出，指尖轻微颤动。她的肩膀保持紧张，呼吸放轻，最后指尖停在石门前方，尚未真正触碰。

## chunk_007：多人互动写法

元数据建议：`content_type=method`，`problem_types=["互动不自然","多人动作混乱","对视僵硬"]`，`action_types=["对视","靠近","回应","并肩行走"]`，`priority=9`。

多人互动不能只写“两个人对视”或“两个人靠近”，要分角色写清楚谁先动、谁回应、动作节奏、双方距离和最后状态。多人互动公式：角色A起始状态 + 角色A动作 + 角色B察觉和回应 + 两人关系变化 + 结束状态 + 镜头构图。

两人对视示例：男子站在桥边，原本低头沉默，随后缓缓抬头看向远处的女子。女子察觉到他的目光后微微停下脚步，身体轻轻转向他，视线与男子短暂相接。两人都没有立刻靠近，只是隔着一段距离安静对视，眼神中带着迟疑、克制和复杂情绪。镜头采用中景横向构图，突出距离感和关系张力。

一人靠近、一人后退：男子向前迈出一步，动作缓慢但带着试探；女子察觉后身体微微后撤，手指收紧衣袖，眼神短暂闪躲。两人的距离没有立刻拉近，最后停在一种紧张而克制的对峙状态。

并肩行走：两人不要同步机械移动，应写出微小差异，例如一人脚步沉稳、一人略慢半步，衣摆和视线各自变化，镜头用中景侧面跟随，保持两人之间的距离和节奏。

## chunk_008：通用提示词模板

元数据建议：`content_type=template`，`problem_types=["提示词太笼统","需要改写"]`，`action_types=["通用"]`，`priority=10`。

通用公式：人物身份 + 场景氛围 + 情绪状态 + 主动作 + 辅助动态 + 身体联动 + 结束状态 + 简单镜头。

人物身份用于明确角色是谁，例如古风红衣女子、受伤少年侠客、神情疲惫的中年男子、紧张的小女孩、端庄的宫廷女子。场景氛围用于描述环境，例如夜晚古街、昏暗山洞、雨中庭院、战斗后的废墟。情绪状态用于说明人物当前状态，例如谨慎、警觉、压抑、犹豫、坚定、疲惫、虚弱。

主动作说明人物主要在做什么，例如缓慢向前行走、回头看向身后、抬头望向前方、伸手触碰石门、慢慢坐下、转身离开。辅助动态加入自然小动作，例如发丝轻轻晃动、衣摆随风摆动、手指微微收紧、呼吸轻微变化、眼神短暂闪躲、肩膀轻轻起伏。身体联动说明动作中各部位如何配合。结束状态说明动作完成后停在哪里、是什么姿势和情绪。简单镜头说明镜头如何配合，例如中近景侧面跟随、缓慢推进到人物面部、正面平稳后退、中景横向构图。

可直接给用户的结构：“可以按这个结构改：人物身份 + 场景氛围 + 情绪状态 + 主动作 + 辅助动态 + 身体联动 + 结束状态 + 镜头。”

## chunk_009：标准输出格式

元数据建议：`content_type=answer_format`，`problem_types=["agent回答规则","输出格式"]`，`priority=8`。

当 agent 检索到本知识库后，回答用户时建议采用三段式：先指出用户问题的原因，再给出优化原则，最后根据用户信息完整度输出提示词。

推荐回答格式：“你的问题主要是动作描述太概括，只写了人物要做什么，没有写清楚人物怎么做、身体怎么联动、情绪如何影响动作。优化时可以按这个结构写：人物身份 + 场景氛围 + 情绪状态 + 主动作 + 辅助动态 + 身体联动 + 结束状态 + 镜头。只有用户提供原始提示词或要求改写某段具体内容时，输出【优化后提示词】；若用户只是泛问方法、生成例子或由 agent 补充场景，输出【示例提示词：具体示例名】。”

## chunk_011：常见问题与回答

元数据建议：`content_type=faq`，`problem_types=["动作幅度","动作速度","现代感","镜头配合","情绪表达"]`，`priority=8`。

动作幅度怎么控制：动作幅度要根据角色身份和场景氛围决定。宫廷女子动作幅度小、端庄克制；侠客动作可更利落有力；小孩动作可轻快活泼；紧张角色动作幅度小、身体收紧；愤怒角色动作可更明显，但不能失控。如果动作太夸张，可以减少大幅度动作，改成肩膀、眼神、手指、衣摆等细节变化。

动作速度怎么控制：在提示词中加入明确速度词，例如缓慢地、轻轻地、平稳地、短暂停顿后、逐渐、慢慢、快速、利落、有节奏地。示例：“她短暂停顿后，缓慢地向前迈出一步，脚步放轻，身体随着动作轻微起伏。”

如何避免动作太现代：古风、仙侠、宫廷角色要避免大幅度挥手、夸张奔跑、现代街拍感走路、过于随意的肢体动作和明显现代姿态。多用克制、端庄、缓慢、平稳、轻移莲步、衣袖轻摆、侧身回望、低头敛目、步伐放轻等表达。

如何写镜头配合：人物向前走适合正面平稳后退、侧面跟随、背后跟拍；人物抬头适合正面中近景缓慢推进；人物转身适合中近景稳定拍摄或轻微推进；多人对视适合中景横向构图并保留人物距离；紧张动作适合缓慢推进或近景突出表情和手部细节。

如何让动作更有情绪：同一个动作在不同情绪下写法不同。低头可以是失落地肩膀下沉、羞涩地眼神闪躲、压抑地手指握紧、愧疚地不敢直视。回头可以是警觉地快速克制、不舍地缓慢停留、震惊地先僵住再回头、犹豫地回到一半停住。
